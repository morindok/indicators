# ORGANISM-2500 (Super-Aware Edition)

> An experimental digital organism simulation with self-observation and meta-cognition modules.

## How to Use

- Run `pip install -r requirements.txt`
- Run `python run.py`

## Notes

- `organism/genome.py`: evolutionary genome.
- `organism/memory.py`: memory systems.
- `organism/language.py`: language module.
- Experimental research code, educational purposes only.
