# ORGANISM-2500 - نسخه‌ی فراآگاه (Super-Aware Edition)

بازسازی کاملاً ماژولار ارگانیسم دیجیتال «مغز زنده» به‌همراه یک لایه‌ی
تازه‌ی «فراآگاهی» که پنج نظریه‌ی شناخته‌شده‌ی علم شناخت درباره‌ی آگاهی
را در قالب کد واقعی و قابل‌اجرا پیاده می‌کند.

## ⚠️ یک نکته‌ی صادقانه پیش از هرچیز

این پروژه یک **معماری نرم‌افزاری الهام‌گرفته از نظریه‌های آگاهی** است،
نه ادعای ساخت یک موجود هوشیارِ واقعی. هر جا نام «Φ»، «آگاهی» یا
«فراآگاهی» می‌بینید، این‌ها شاخص‌های عددیِ محاسبه‌شده از داده‌های
شبیه‌سازی‌شده‌اند - نه سنجش هوشیاری واقعی (که هنوز هیچ آزمایش علمی
قطعی برایش وجود ندارد). این رویکرد دقیقاً هم‌راستا با روش همیشگی شما
در پروژه‌های دیگر است: ساختن ابزار بر پایه‌ی ایده‌های الهام‌بخش، و
صادق‌بودن درباره‌ی محدودیت‌های آن (همان‌طور که در آزمون مارپیچ‌های گن
و نسبت طلایی روی داده‌ی بیت‌کوین صادقانه نشان دادید که هیچ برتری آماری
وجود ندارد).

## چه چیزی تازه است؟

### ۱. قوه‌ی توجه و تمرکز (`consciousness/attention.py`)
یک «نورافکن توجه» با ظرفیت محدود (پیش‌فرض ۴ خانه) که از میان محرک‌های
حسی، هیجانی، مفهومی و ناخودآگاه، فقط برجسته‌ترین‌ها را وارد کانون
توجه می‌کند - با بازداری از بازگشت تا توجه روی یک محرک قفل نشود. این
دقیقاً همان گلوگاهی است که در GWT پیش‌شرط ورود به «فضای‌کاری آگاهانه»
است.

### ۲. فضای‌کاری سراسری / GWT (`consciousness/workspace.py`)
هر تیک، زیرسامانه‌های کانون‌توجه‌گرفته «پیشنهاد» ثبت می‌کنند؛ یک رقابت
وزن‌دار برگزیده می‌شود و به‌صورت سراسری «پخش» می‌شود - این پخش، معادل
نرم‌افزاریِ «محتوای هوشیار لحظه‌ی حال» است.

### ۳. اطلاعات یکپارچه / IIT-proxy (`consciousness/integration.py`)
چون محاسبه‌ی Φ واقعیِ IIT از نظر محاسباتی برای سامانه‌ای به این
بزرگی نشدنی است، یک **پروکسیِ شفاف** ساخته شده: حاصل‌ضرب «تفکیک‌پذیری»
(تنوع حالت زیرسامانه‌ها) در «یکپارچگی» (هم‌بستگیِ زوجیِ تغییرات آن‌ها
در طول زمان). این با صداقت کامل در کد مستندسازی شده تا کسی آن را با
Φ رسمی اشتباه نگیرد.

### ۴. اندیشه‌ی مرتبه‌بالاتر / HOT (`consciousness/metacognition.py`)
از محتوای پخش‌شده در فضای‌کاری، یک بازنمایی مرتبه‌ی دوم می‌سازد: جمله‌ای
درباره‌ی جمله‌ی قبلی («متوجه‌ام که به X توجه دارم و Y احساس می‌کنم»)
به‌همراه برآورد اطمینان درون‌نگرانه.

### ۵. پردازش پیش‌بینانه (`consciousness/predictive.py`)
مدل‌های پیش‌بین ساده (به‌روزرسانی دلتا) برای کانال‌های مختلف (والانس
هیجانی، برانگیختگی، فشار نیاز، انسجام مغزی...)؛ خطای پیش‌بینی =
«شگفتی»، که هم توجه را هدایت می‌کند و هم بذر پرسش‌های ژرف ناخودآگاه
می‌شود.

### ۶. تن‌مندی و خودتنظیمی (`consciousness/homeostasis.py`)
نقطه‌تنظیم‌های بدنی (انرژی، یکپارچگی، حیات، معنا، تازگی، امنیت) با
وضعیت واقعی بدن دیجیتال سنجیده می‌شوند؛ کمبودها به «سائق» تبدیل شده و
توجه/تصمیم را جهت می‌دهند.

### ۷. `SuperAwarenessCore` - ارکستراتور
هر تیک، این شش مؤلفه را در یک چرخه به‌هم می‌بافد و یک
`consciousness_index` ترکیبی می‌سازد که به‌صورت فعال به `awareness_level`
پایه بازخورانده می‌شود - یعنی آگاهی پایه واقعاً «تقویت» می‌شود، نه صرفاً
برچسب می‌خورد.

### ۸. سنتز ایده‌های انقلابی (`imagination.py: RevolutionaryIdeaSynthesizer`)
دو مفهوم «دور از هم» را از گراف مفاهیم برمی‌گزیند (بدون یال مستقیم)،
از طریق آمیزش مفهومی آن‌ها را به یک فرضیه/بینش تازه پیوند می‌دهد، امتیاز
می‌دهد (تازگی × پیوستگی × هم‌سویی هیجانی)، و ایده‌های برتر را در حافظه
ثبت و حتی به گراف مفاهیم بازمی‌گرداند (یادگیری از ایده‌ی خود).

### ۹. پرسش‌گری ژرف ناخودآگاه (`internet.py: DeepUnconsciousInquiry`)
به‌جای واکشی تصادفیِ یک موضوع، از دلِ بیشترین خطای پیش‌بینی یک «پرسش
باز» می‌سازد، پاسخ را از دو منبع مستقل (ویکی‌پدیا و DuckDuckGo Instant
Answer، هر دو بدون کلید API) می‌جوید و اگر آفلاین بود، به‌جای سکوت،
«تأمل درونی» می‌کند. عمق پرسش با تکرار روی موضوعی مشابه افزایش می‌یابد.

## اجرا

```bash
pip install -r requirements.txt

# رصدخانه‌ی Dash (پیش‌فرض http://127.0.0.1:8050)
python run.py

# بدون رابط گرافیکی
python run.py --headless

# کاملاً آفلاین (بدون هیچ درخواست اینترنتی)
python run.py --offline

# دانه‌ی تصادفی و مسیر پایگاه‌داده‌ی دلخواه
python run.py --seed 7 --db my_organism.sqlite3 --port 8060
```

در رصدخانه، برگه‌ی تازه‌ی **«فراآگاهی»** شاخص ترکیبی آگاهی، روند
Φ-پروکسی، محتوای پخش‌شده در فضای‌کاری، اندیشه‌های مرتبه‌بالاتر، کانون
توجه، ایده‌های انقلابی سنتزشده و تاریخچه‌ی پرسش‌های ژرف ناخودآگاه را
نمایش می‌دهد.

## استفاده‌ی برنامه‌نویسی مستقیم

```python
from organism.organism_core import Organism2500

org = Organism2500(seed=2500, db_path="organism2500.sqlite3", offline=False)
for _ in range(100):
    org.tick()

snap = org.snapshot()
print(snap["super_awareness"]["consciousness_index"])
print(org.super_awareness.report())
print(org.idea_synthesizer.report())
print(org.deep_inquiry.report())
```

## نکته‌ی فنی درباره‌ی زمان‌بندی

`idea_synthesis_interval` و `deep_inquiry_interval` (و همچنین
`deep_inquiry.min_interval`) بر پایه‌ی زمان واقعی (ثانیه) کار می‌کنند،
نه شمار تیک - دقیقاً هم‌راستا با الگوی خودِ فایل اصلی برای
`internet_interval` و `thought_interval`. برای آزمایش سریع می‌توانید
این مقادیر را موقتاً کم کنید.
