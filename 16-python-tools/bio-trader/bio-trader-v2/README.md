# BioTrader 2500 v2

> Second version of the Python + Dash crypto analysis dashboard for Bybit USDT perpetual futures.

## How to Use

- Run `pip install -r requirements.txt`
- Run `python app.py` and open `http://127.0.0.1:8050`

## Notes

- Multi-symbol scanner with maker/taker fee aware backtesting.
- ATR-based risk levels and EMA trend filtering.
- TradingView screen connection helpers included.
