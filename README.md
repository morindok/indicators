# TradingView & Python Indicators Collection

A comprehensive collection of **28 categories** and **hundreds of technical analysis indicators** for Pine Script (TradingView) and Python: spirals, mirrors, Gann, Ichimoku, volume, footprint, Smart Money concepts and automated signals.

![Categories](https://img.shields.io/badge/Categories-28-blue) ![Type](https://img.shields.io/badge/Type-Pine_Script_%2B_Python-green) ![Use](https://img.shields.io/badge/Use-Educational-orange)

## Quick Start

- **TradingView indicator:** copy the file code into the Pine Editor and click *Add to Chart*.
- **Python tool:** run `python script.py` (Python 3.10+ required).
- **Tutorial:** every indicator has its own `.md` guide with installation, usage and trading tips.
